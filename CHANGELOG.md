# Changelog

## 1.4.1

- Default Angry Pigs to a neon pixel night scene with a moon, sparse stars, blue-purple hills and luminous grass edges.
- Add a day/night button next to Join / Leave. Preserve active gameplay and scores, and save the selection across reloads and game changes.
- Use distinct bright bird outlines, a lime-and-pink pig palette, visible sling bands, cyan aiming dots and bright impact fragments at night.
- Include the previously local-only Angry Pigs game in the public prebuilt package.

## 1.4.0 (local preview; not published)

- Add Angry Pigs: original pixel blue sky, clouds, grass and soil, a bottom sling and five bird silhouettes flying in both directions.
- Add unlimited pig reloading, pull-strength launch velocity, a gravity-matched dotted aiming parabola and swept collision detection.
- Shatter pigs immediately on a hit; let birds tumble to the ground before producing colored pixel fragments.
- Add a persistent game picker alongside the game-background toggle. Switching games cancels aim, releases pointer capture and removes the previous scene.
- Keep the GitHub repository, release and market submission unchanged in this local update.

## 1.3.1

- Prepare public distribution: standalone installation documentation, compatibility notes, screenshots, release packaging and checksums.
- Add package validation, CI and tag-triggered GitHub Release workflow.
- Keep the 1.3.0 theme and gameplay unchanged.

## 1.3.0

- Add an explicit Join / Leave game button and mouse-drag flight controls.
- Keep automatic firing and unlimited respawns during manual control.
- Restore chat focus on exit; release pointer capture and local listeners on blur, navigation or disabling.

## 1.2.0

- Add an optional pixel air-battle background with continuous enemy waves, mutual fire and collision detection.
- Add unlimited automatic respawns, entity limits and hidden-window pausing.
- Restore original scenery when the game is turned off.

## 1.1.3

- Use a single faint gray-blue scan line with a slow downward loop and a short trail.

## 1.1.0–1.1.2

- Add original pixel stars, invaders, UFOs, hearts, coins, ships, blocks, a city silhouette and arcade corners.
- Add independent pixel decoration preferences and refine CRT rendering.

## 1.0.0

- Initial desktop theme with dark/light palettes, native settings, glow/grid controls and a pixel whale.
