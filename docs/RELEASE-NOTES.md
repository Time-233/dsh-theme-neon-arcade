NEON ARCADE 1.4.2：更新 Windows 桌面端兼容性声明，DeepSeek Harness 0.2.1-rc.1～0.2.1-rc.5 均已验证成功。验证范围依据作者于 2026-11-01 确认的实际验证结果，已同步至插件清单。主题和小游戏运行代码与 1.4.1 相同。

- 鼠标左键拖动战机，自动射击，中弹无限复活；Esc 或「退出参与」恢复聊天。
- 独立辉光、网格、像素点缀和单条低亮度 CRT 扫描线开关。
- 游戏默认关闭，关闭后恢复原场景；独立 Web 客户端不会启用。
- 新增蓝天、白云、草地、底部弹弓、无限小猪和五种飞鸟。拉动距离决定发射速度，瞄准虚线与实际飞行使用同一重力模型。
- 命中后小猪立即粒子碎散，小鸟先坠落，落地后产生像素碎片。新增游戏选择，两种游戏互斥运行。
- 右上角「切换白天 / 切换夜晚」保留当前分数和参与状态，并记住选择。夜间鸟与猪采用明亮像素轮廓，弹弓、轨迹和粒子均有独立夜间配色。

**已验证：Windows / DeepSeek Harness 0.2.1-rc.1、0.2.1-rc.2、0.2.1-rc.3、0.2.1-rc.4、0.2.1-rc.5。其他版本与系统尚未验证。**

从本 Release 下载 **dsh-theme-neon-arcade.tgz** 或 **dsh-theme-neon-arcade-1.4.2.tgz**，在桌面端「插件 → 添加插件」填写下载文件的绝对路径，安装并启用。设置位置：「更多 → 设置 → 通用设置 → NEON ARCADE → 启用小游戏背景 → 游戏选择 → 愤怒的小猪」。点击「参与游戏」，按住底部小猪向下或侧后拉动，松开发射；Esc 退出。

Compatibility metadata update: Windows / Harness 0.2.1-rc.1 through 0.2.1-rc.5 have been successfully tested, as confirmed by the author on 2026-11-01. All five releases are marked compatible in the manifest. Theme and game runtime are unchanged from 1.4.1, including air battle, Angry Pigs and the persistent neon day/night switch.
