# Changelog

## 1.3.1

- Prepare public distribution: standalone installation documentation, compatibility notes, screenshots, release packaging and checksums.
- Add package validation, CI and tag-triggered GitHub Release workflow.
- Keep the 1.3.0 theme and gameplay unchanged.

## 1.3.0

- Add an explicit Join / Leave game button and mouse-drag flight controls.
- Keep automatic firing and unlimited respawns during manual control.
- Restore chat focus on exit; release pointer capture and local listeners on blur, navigation or disabling.

## 1.2.0

- Add an optional pixel air-battle background with continuous enemy waves, mutual fire and collision detection.
- Add unlimited automatic respawns, entity limits and hidden-window pausing.
- Restore original scenery when the game is turned off.

## 1.1.3

- Use a single faint gray-blue scan line with a slow downward loop and a short trail.

## 1.1.0–1.1.2

- Add original pixel stars, invaders, UFOs, hearts, coins, ships, blocks, a city silhouette and arcade corners.
- Add independent pixel decoration preferences and refine CRT rendering.

## 1.0.0

- Initial desktop theme with dark/light palettes, native settings, glow/grid controls and a pixel whale.
