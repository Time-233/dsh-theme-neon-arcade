NEON ARCADE 为 DeepSeek Harness 桌面端提供霓虹像素主题，以及可开关、可参与的像素空战背景。

- 鼠标左键拖动战机，自动射击，中弹无限复活；Esc 或「退出参与」恢复聊天。
- 独立辉光、网格、像素点缀和单条低亮度 CRT 扫描线开关。
- 游戏默认关闭，关闭后恢复原场景；独立 Web 客户端不会启用。
- 此版本整理公开安装说明、预构建插件包和 SHA-256 校验文件，游戏行为与 1.3.0 相同。

**已验证：Windows / DeepSeek Harness 0.2.1-rc.2。其他版本与系统尚未验证。**

下载附件 **dsh-theme-neon-arcade.tgz**，在桌面端「插件 → 添加插件」填写文件绝对路径，安装并启用。无需自行构建或安装 Node.js。设置位置：「更多 → 设置 → 通用设置 → NEON ARCADE」。

The prebuilt tarball is ready to install in DeepSeek Harness desktop via Plugins → Add plugin → absolute path to the downloaded file. Tested on Windows with Harness 0.2.1-rc.2. Source is MIT licensed; the bundled Silkscreen font uses SIL OFL 1.1.
